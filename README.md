# PRODIGY_FS_04 — Real-Time Chat Application
 
A real-time chat application built with Node.js, Express, and Socket.io
as Task 4 of the Prodigy Infotech Full Stack Development Internship.
 
## Features
- Create a username and join a chat room
- Real-time group messaging (WebSocket-powered, no page reloads)
- Private 1-to-1 conversations
- Online user presence list
- Typing indicator
- Image sharing
- Chat history for the last 100 messages per room
 
## Tech Stack
Node.js, Express, Socket.io, HTML/CSS/JavaScript
 
## How to run locally
1. Clone this repo: git clone https://github.com/YOUR-USERNAME/PRODIGY_FS_04.git
2. cd PRODIGY_FS_04
3. npm install
4. npm run dev
5. Open http://localhost:3000 in two or more browser windows
